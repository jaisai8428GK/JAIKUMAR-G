# Internal Mark Management System

A simple and efficient web application for managing **students, subjects, and internal marks** using PHP and MySQL.

## About

The **Internal Mark Management System** is designed to make the process of recording and managing student internal marks easier and more organized.

It reduces manual work and provides a simple way to store, update, and view academic records.

## Features

* Manage student details
* Manage subjects
* Enter internal marks
* Update marks
* View student records
* Calculate total marks
* Store data in MySQL
* User login
* Easy-to-use interface
