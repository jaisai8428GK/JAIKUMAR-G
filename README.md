# Internal Mark Management System

A simple web-based application for managing students' internal marks using **PHP and MySQL**.

## Features

* Student management
* Subject management
* Add and update marks
* View student marks
* Calculate marks
* Store data securely in MySQL

## Technologies

* HTML
* CSS
* PHP
* MySQL
* XAMPP

## How to Run

1. Install **XAMPP**.
2. Start **Apache** and **MySQL**.
3. Copy the project into the `htdocs` folder.
4. Create the database in **phpMyAdmin**.
5. Import the provided `.sql` file.
6. Open the project in your browser:

```text
http://localhost/Internal-Mark-Management-System/
```

## Purpose

This system makes internal mark management **simple, organized, and efficient**.
